# Ali Soleimani — LFTN Candidate Profile

English-language static website for the Ludwig Fresenius Talent Network application.

## Files
- `index.html` — main page
- `style.css` — responsive styling
- `scripts.js` — mobile navigation
- `assets/ali-portrait.jpg` — portrait extracted from the current CV

## Publish on GitHub Pages
1. Create a repository, for example `lftn-candidate`.
2. Upload all files/folders from this package to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for GitHub Pages to publish.

Suggested URL:
`https://alisoleimani71.github.io/lftn-candidate/`

The website content and navigation are fully in English.
Official LFTN links point to StudyPLUS / Hochschule Fresenius.
