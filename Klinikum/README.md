# Ali Soleimani — Klinikum Leverkusen Application Site

A clean, responsive one-page portfolio/application site tailored to the Strategischer Einkäufer (m/w/d) application.

## Files
- `index.html` — page structure and content
- `style.css` — visual design and responsive layout
- `script.js` — small navigation interaction
- `assets/` — reserved for future images/icons

## Deploy on GitHub Pages
1. Create a repository (or use your existing website repository).
2. Upload `index.html`, `style.css`, `script.js`, and `assets/`.
3. Make sure `index.html` is in the repository root.
4. Go to Settings → Pages.
5. Choose `Deploy from a branch`, select `main`, folder `/ (root)`.
6. Save and wait for the GitHub Pages deployment.

## Important
The site intentionally does not claim healthcare procurement or AMOR experience. It positions the transferable procurement strengths from the CV: strategic sourcing, supplier management, RFQ/tendering, commercial evaluation, negotiation, contracts, purchase orders and delivery follow-up.
